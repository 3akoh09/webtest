# Ірина Кузик — Бухгалтер для ФОП

Лендінг у преміальному dark-luxury стилі на Next.js 14 + TypeScript + Tailwind + Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

## Продакшн-перевірка

```bash
npm run build
npm run start
```

## Налаштування

Скопіюйте `.env.local.example` в `.env.local` і заповніть значення.
